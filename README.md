# Undercheck

Sitio de Undercheck — agencia de desarrollo web, automatizaciones, publicidad y
datos, potenciada por IA. Construido con Next.js (App Router), Tailwind CSS y
GSAP/Lenis para las animaciones.

El sitio estático original (ticketera) queda preservado en la rama `old`.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Deploy

Pensado para deployar en Vercel (importar el repo desde GitHub). El dominio
`undercheck.com.ar` hoy apunta a GitHub Pages — el cambio de DNS a Vercel se
hace recién después de validar el sitio en una preview.
